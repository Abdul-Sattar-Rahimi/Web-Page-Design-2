# Web-Page-Design-2
##پروژه دوم طراحی صفحات وب استاد رحمت اله ذاکری

دانشجو: عبدالستار رحیمی

# خبرگزاری نوین

پروژه طراحی صفحه‌ی خبری با بوت‌استرپ (نسخه‌ی RTL)

## منابع بوت‌استرپ استفاده‌شده در این صفحه

---

## ۱. منوی بالای سایت (Navbar)

کلاس‌های استفاده‌شده: `navbar` `navbar-expand-md` `navbar-dark` `bg-dark` `navbar-brand` `navbar-toggler` `navbar-toggler-icon` `collapse` `navbar-collapse` `navbar-nav` `mr-auto` `nav-item` `nav-link`

استفاده از کامپوننت Navbar بوت‌استرپ برای منوی اصلی و دکمه‌ی همبرگری در حالت موبایل:

- Navbar:
  https://getbootstrap.com/docs/4.6/components/navbar/

---

## ۲. بنر بزرگ تصویری (Jumbotron)

کلاس‌های استفاده‌شده: `jumbotron` `jumbotron-fluid` `display-4` `lead`

استفاده از کامپوننت Jumbotron برای بنر تمام‌عرض بالای صفحه همراه با تایپوگرافی بوت‌استرپ برای عنوان و زیرعنوان:

- Jumbotron:
  https://getbootstrap.com/docs/4.6/components/jumbotron/
- Typography:
  https://getbootstrap.com/docs/4.6/content/typography/

---

## ۳. چیدمان کلی محتوا (Grid System)

کلاس‌های استفاده‌شده: `container` `row` `col-md-8` `col-md-6` `col-sm-6` `col-md-4`

استفاده از سیستم گرید برای تقسیم صفحه به ستون اصلی اخبار و ستون کناری، و همچنین چیدمان دو ستونه‌ی کارت‌های خبری:

- Grid:
  https://getbootstrap.com/docs/4.6/layout/grid/

---

## ۴. کارت‌های خبری

کلاس‌های استفاده‌شده: `card` `card-img-top` `card-body` `card-title` `card-text` `h-100`

استفاده از کامپوننت Card برای نمایش هر خبر به همراه تصویر، عنوان و خلاصه‌ی متن:

- Card:
  https://getbootstrap.com/docs/4.6/components/card/

---

## ۵. برچسب دسته‌بندی و شمارش بازدید (Badge)

کلاس‌های استفاده‌شده: `badge` `badge-danger` `badge-success` `badge-warning` `badge-info` `badge-primary` `badge-pill`

استفاده از کامپوننت Badge برای نشان دادن دسته‌بندی خبر (سیاسی، اقتصادی، ورزشی، فرهنگی) و تعداد بازدید در بخش پربازدیدترین‌ها:

- Badge:
  https://getbootstrap.com/docs/4.6/components/badge/

---

## ۶. لیست پربازدیدترین‌ها و دسته‌بندی‌ها (List Group)

کلاس‌های استفاده‌شده: `list-group` `list-group-flush` `list-group-item` `d-flex` `justify-content-between` `align-items-center`

استفاده از کامپوننت List Group برای نمایش لیست خبرهای پرطرفدار و لیست دسته‌بندی‌ها در ستون کناری، همراه با یوتیلیتی‌های فلکس‌باکس برای چیدمان عنوان و عدد بازدید کنار هم:

- List group:
  https://getbootstrap.com/docs/4.6/components/list-group/
- Flex:
  https://getbootstrap.com/docs/4.6/utilities/flex/

---

## ۷. فرم عضویت در خبرنامه (Forms)

کلاس‌های استفاده‌شده: `form-group` `form-control`

استفاده از کامپوننت Forms برای ساخت فیلد ورودی ایمیل در کارت خبرنامه:

- Forms:
  https://getbootstrap.com/docs/4.6/components/forms/

---

## ۸. دکمه‌ها (Buttons)

کلاس‌های استفاده‌شده: `btn` `btn-outline-primary` `btn-sm` `btn-dark` `btn-block`

استفاده از کامپوننت Buttons برای دکمه‌ی «ادامه مطلب» در هر کارت خبری و دکمه‌ی «عضویت» در فرم خبرنامه:

- Buttons:
  https://getbootstrap.com/docs/4.6/components/buttons/

---

## ۹. فوتر

کلاس‌های استفاده‌شده: `bg-dark` `text-light` `bg-secondary` `bg-transparent` `text-justify` `text-center` `border-bottom` `small`

استفاده از کلاس‌های رنگی و یوتیلیتی‌های متن بوت‌استرپ برای پس‌زمینه‌ی تیره‌ی فوتر، خط جداکننده و تراز متن:

- Colors:
  https://getbootstrap.com/docs/4.6/utilities/colors/
- Borders:
  https://getbootstrap.com/docs/4.6/utilities/borders/
- Text:
  https://getbootstrap.com/docs/4.6/utilities/text/
